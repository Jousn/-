# Fork 仓库链接

## 项目原始仓库

https://github.com/multica-ai/multica

## Fork 仓库（示例）

如果你已经 Fork 了项目，你的仓库链接格式为：

```
https://github.com/你的GitHub用户名/multica
```

例如：
```
https://github.com/example-user/multica
```

---

## 如何 Fork 项目

### 1. 访问原始仓库

打开浏览器，访问：
https://github.com/multica-ai/multica

### 2. 点击 Fork 按钮

在页面右上角，点击 **Fork** 按钮。

### 3. 选择 Fork 选项

- **Owner**：选择你的 GitHub 用户名
- **Repository name**：保持默认 `multica`
- **Description**：可选，填写仓库描述
- **Copy the main branch only**：建议勾选

### 4. 等待 Fork 完成

GitHub 会自动创建你的个人仓库副本，完成后跳转到你的 Fork 页面。

### 5. 克隆 Fork 仓库到本地

```bash
git clone https://github.com/你的用户名/multica.git
cd multica
```

---

## 保持 Fork 与上游同步

### 1. 添加上游仓库为远程源

```bash
git remote add upstream https://github.com/multica-ai/multica.git
```

### 2. 拉取上游更新

```bash
git fetch upstream
```

### 3. 合并上游更改

```bash
git checkout main
git merge upstream/main
```

### 4. 推送更新到你的 Fork

```bash
git push origin main
```

---

## 注意事项

1. **Fork 是公开操作**：Fork 后，你的仓库副本对所有人可见
2. **保持同步**：定期从上游拉取更新，避免代码过时
3. **分支管理**：建议为每个修复创建独立分支（如 `fix/ws-reconnect-state-sync`）
4. **提交规范**：遵循项目的 Commit Message 规范
